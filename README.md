# 특성 뽑기 슬롯

레버를 당기면 특성이 슬롯머신처럼 돌아가는 뽑기 페이지입니다. 희귀한 등급일수록 연출이 커집니다.
`index.html` 파일 하나로 되어 있어서 서버 없이 GitHub Pages에 올리거나 파일 그대로 보내도 동작합니다.

## 기능

- **등급 7단계**: 기본 → 커먼 → 언커먼 → 레어 → 에픽 → 레전더리 → 신화. 등급이 올라갈수록 연출이 더해집니다.
- **확률표**: 등급별 확률과 특성 1개당 확률을 표로 보여 줍니다.
- **확률 설정**: 등급마다 확률(%)과 특성 이름(쉼표나 줄바꿈으로 구분)을 바꿉니다. 등급마다 있는 `연출 미리보기`로 그 등급의 연출을 바로 볼 수 있습니다.
- **스킨**: 기본 스킨 10개와 직접 만드는 `내 스킨`이 있습니다. 내 스킨에서는 배경(단색·그라데이션·무늬·이미지), 슬롯머신 색상·모양·글꼴, 제목 문구를 바꿀 수 있습니다.
- **공유**: 지금 특성·확률·스킨이 담긴 링크를 만듭니다. 파일로 보낼 때는 `설정 코드`를 함께 보내면 됩니다.

설정은 각자 브라우저(localStorage)에 저장됩니다. 친구가 링크로 받은 설정을 바꿔도 보낸 사람 쪽에는 영향이 없습니다.
배경 이미지는 용량 때문에 공유 링크에 담기지 않습니다.

## 배포 (GitHub Pages)

1. 이 저장소를 GitHub에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://a01088470676-debug.github.io/trait-gacha/`에서 열립니다.

공유 링크가 가리키는 주소는 `index.html`의 `SITE_URL` 상수입니다. 저장소 이름이나 주소가 바뀌면 이 값도 같이 바꿔 주세요.
