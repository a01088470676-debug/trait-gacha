# 특성 뽑기 슬롯

레버를 당기면 특성이 슬롯처럼 돌아가는 뽑기 페이지입니다. 희귀한 등급일수록 연출이 깊어집니다.
서버 없이 GitHub Pages에 올리거나, 폴더째 압축해서 보내도 동작합니다.

## 기능

- **1회 뽑기 / 10회 뽑기**: 레버, `1회 뽑기` 버튼, `Space` 키로 1회를 뽑습니다. 10회는 빠르게 이어서 돌리고, 레어 이상이 나올 때만 연출을 보여 준 뒤 마지막에 10개 결과를 모아 보여 줍니다(`건너뛰기` 가능). 천장(몇 번 뽑으면 확정)은 없습니다.
- **등급 7단계와 연출**
  - 기본 · 커먼 · 언커먼: 릴이 결과에 멈춘 뒤 릴 창 안에서 조용히 공개됩니다.
  - 레어 · 에픽 · 레전더리 · 신화: 릴은 뒤에서 계속 돌고, 화면 중앙에서 특성 이름이 공개됩니다. 화면을 누르면 닫히고 릴이 결과 칸에 멈춥니다.
- **확률표 / 확률 설정**: 등급별 확률과 특성 이름을 바꿉니다. 등급마다 `연출 미리보기`가 있습니다.
- **스킨**: 기본 10개와 직접 만드는 `내 스킨`(배경 이미지 포함).
- **공유**: 특성·확률·스킨이 담긴 링크 또는 설정 코드를 만듭니다.

설정은 각자 브라우저(localStorage)에 저장됩니다.

## 파일 구조

```
index.html          HTML 구조만 (CSS/JS 불러오기)
css/base.css        토큰, 페이지 배치, 버튼, 창(dialog), 폼
css/machine.css     슬롯머신 몸체, 릴 창, 결과판, 레버, 모양 변형
css/traits.css      등급 색, 등급별 표시(칩, 릴 결과, 확률표, 10회 카드)
css/effects.css     뽑기 연출 전용 스타일
js/traitData.js     등급(TRAIT_TIERS), 기본 확률·특성, 확률 계산, 공용 도구
js/audio.js         효과음 (Web Audio 합성)
js/effects.js       모든 연출 (playBasicEffect ~ playMythicEffect)
js/slotMachine.js   레버, 릴 회전·정지, 결과 선택, 1회/10회 뽑기
js/main.js          시작, 스킨, 창, 확률 설정, 공유, 최근 결과
```

스크립트는 ES 모듈이 아닌 일반 `<script>`로 불러옵니다. 그래서 `index.html`을 더블클릭해서 열어도 동작합니다.
파일끼리는 전역 이름공간 `TG`로 연결됩니다.

## 연출 테스트

브라우저 콘솔에서 등급을 지정해 바로 뽑을 수 있습니다(최근 결과에는 남지 않음).

```js
testTrait('mythic')   // 또는 testTrait('신화'), testTrait(6)
```

## 배포 (GitHub Pages)

1. 이 저장소를 GitHub에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://a01088470676-debug.github.io/trait-gacha/`에서 열립니다.

공유 링크가 가리키는 주소는 `js/main.js`의 `SITE_URL` 상수입니다. 저장소 이름이나 주소가 바뀌면 이 값도 같이 바꿔 주세요.
